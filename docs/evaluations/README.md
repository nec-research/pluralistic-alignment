# Evaluation Results

Record evaluation results here. Create one markdown file per evaluation run.

## Naming convention

`YYYY-MM-DD-<short-description>.md`

## Template

```markdown
# <Title>

**Date:** YYYY-MM-DD
**Models:** (list models evaluated)
**Data:** (seed count, varieties, source)

## Setup

(Configuration, arm conditions, number of iterations, etc.)

## Results

(Tables, key metrics, observations)

## Notes

(Anything noteworthy, issues encountered, follow-ups)
```
